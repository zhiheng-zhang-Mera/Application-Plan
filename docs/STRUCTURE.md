# Repository Structure

- `README.md` — 30-second dashboard
- `STRATEGY.md` — screening rules
- `STATUS.md` — current operational snapshot
- `data/` — canonical machine-readable state
- `targets/` — filtered candidate views
- `applications/` — real application workflows
- `materials/` — reusable research/application materials
- `automation/` — agent contracts
- `archive/` — historical material only
- `Documents/` — original source documents

If Markdown and YAML disagree, treat `data/*.yaml` as canonical and fix the Markdown view.
