## 懒人筛选规则

**直接淘汰**：GRE required / 强制重新考英语且不能豁免 / 明显自费或 funding 不够 / 学术层级明显低于底线 / 新西兰。

**强烈扣分**：强制笔试、多轮 technical panel、必须长期套磁、重 proposal、高申请摩擦。

**加分**：全奖覆盖好、直接申请、少面试、coding/systems/agentic AI 友好、生活成本可控。

**小参考**：LGBT/trans 日常环境、ACG/二次元生态。二者只用于条件接近时 tie-break，不覆盖 admission / funding 硬条件。
