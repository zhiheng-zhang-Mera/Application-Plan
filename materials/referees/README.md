# 推荐人控制中心

> 目标：把推荐信流程做成“低摩擦、低记忆负担”的可复用模块。
>
> 核心规则：**只记录推荐人真实知道的内容；新项目只作为“上次联系后新增信息”介绍，不倒推成他们曾经了解或指导过。**

|---|---|---|---|

| Ting Dang | 用户先准备 draft，老师 review / 自行决定如何修改与提交 | 保留旧 draft 作为历史基线；仅在她再次需要 draft 时更新 | Boss/Hns/Utopia 均需按“课后独立新项目”处理 |

## 三条硬规则

1. **Known ≠ inferred**：不能因为项目现在重要，就写成老师过去已经知道。
2. **Independent ≠ supervised**：课后独立项目不能包装成推荐人指导项目。
3. **Draft ≠ submitted letter**：旧 draft 只代表“提供给老师 review”，不知道最终采用多少。

## 使用方式

申请新学校时：

1. 查看对应 `known-to-referee.md`；
2. 从 `new-since-last-contact.md` 选 2–4 条真正相关的更新；
3. 按推荐人的既有协作习惯发请求；
4. **给推荐人的实际邮件与可转发英文介绍保持英语。**
