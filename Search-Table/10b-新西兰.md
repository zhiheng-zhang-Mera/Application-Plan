> 补贴政策出处（全国口径）：Universities New Zealand 官方页 "With New Zealand's PhD package for international students ... **Pay the same fees as New Zealanders**"。属全国性政策而非单校优惠。

**本区结构性事实（先读，决定整区定位）**

1. **国际 PhD 按本地学费收费是新西兰全国性政策**，不是个别学校优惠：Auckland 官方原文 "A New Zealand government funding scheme enables the University of Auckland to offer PhD study to international students for the same tuition fees as New Zealand PhD students"，2027 年 **NZ$9,378/年**（另加 Student Services Fee 约 NZ$1,158）。这是全球发达英语国家里唯一"读博学费等同本地生"的通道，也是本区唯一可"自费读博"的发达英语国家。
2. 前提是**在新西兰境内完成博士**（可海外研究累计不超过 12 个月），失去本地资格即按国际价（同页列出 2027 国际价 NZ$58,178.40 / 2028 NZ$61,668 用于非 PhD 类博士）。
3. PhD 学生签证附带：无限工作权、配偶开放工签、子女按本地生学费上学、毕业后 3 年 post-study 工签（Auckland 官方页明列）。
4. 博士注册本质是**学生（student）而非雇员（employee）**：要交学费、奖学金才是收入来源，这一点与澳洲 RTP/欧洲岗位制不同。
5. 因此本区的正确打法不是"抢全奖"，而是"**先锁定导师 → 拿 admission → 同时冲奖学金；奖学金不中则自费，总成本仍远低于美/澳/英**"。

## 二、分区结论（10 条）

- **① 新西兰是本轮"最现实的保底"，但必须把两件事分开：录取是保底，奖学金不是。** 全区 7 校**没有一所**对国际生提供 guaranteed 博士奖学金；而"低学费 + 门槛温和 + 允许硕士在读申请"这三点同时成立，使**录取概率（25–50%）**显著高于美/英/港同档项目，但**拿奖学金概率只有 5–18%**。正确预期：把新西兰当"**付得起、进得去**"的保底，而不是"能拿全奖"的保底。
- **② 学费（2027，全部官方）**：Auckland **NZ$9,378**（明文国际=本地）、Otago **NZ$9,765**（2026 值）、Waikato **NZ$8,519**（2027）、Massey **NZ$8,550**（2027）、AUT **NZ$10,165.67**（2027，含学生服务费）、Canterbury **NZ$9,084–10,940**（2027 估值）、VUW **仅指示性 NZ$9,900–10,000（2024 标注）**。→ **VUW 是唯一没有 2027 精确数字的一所**，是本表最需要补的一格。全国政策依据：Universities New Zealand "Pay the same fees as New Zealanders"；前提是**在新西兰境内就读**（海外研究累计 ≤12 个月，超期转国际价）。
- **③ stipend 排序（年）**：Auckland 35,468 ＞ AUT 34,737 ＞ Otago 34,128 ＞ Waikato 33,000 ＞ VUW 32,000 ＞ Canterbury 32,650（现页示例）/28,000（条例基值）＞ Massey 90,000/3 年 ≈ 30,000。**金额都落在 NZ$30k–35k**，正好覆盖学费（~NZ$10k）+ 生活费（~NZ$25k）——这是新西兰奖学金"够活"的原因。
- **④ 三条 guaranteed 路线对他全部关闭**：Auckland 只给"毛利/太平洋 + NZ 大学 GPA 7.0"；VUW 要"NZ 大学近 12 个月内完成 + GPA 8.5"；AUT VC's 要"NZ 院校 + GPA 8.0"。→ 他是纯竞争池，且多数学校的奖学金线（UC GPA 7.0、Massey GPA 7.0、AUT 一等荣誉）明显高于录取线（5.5–6.0）。
- **⑤ 导师门槛三分法（本区最关键的结构差异）**：**必须先拿导师书面同意**＝Canterbury（须"upload evidence"）、Otago（系里 "informally agreed"）、Waikato（须 **Invitation to Apply**，否则不受理）、Massey（Head of School 同意）、AUT（学院先确认导师）；**不必先找但实际要**＝Auckland（"not required to nominate"，但 "subject to staff availability for supervision"）；**委员会制、不要求**＝VUW（明文 "not required to identify a supervisor"，且 "individual supervisors may not give any undertaking"）。→ **VUW 是全区唯一可以"不套磁就投"的一所**，也是唯一导师无法预先锁定的学校。
- **⑥ 英语：7 校全部可用"英语授课学位"通过，但省事程度差三档。** 最干脆＝**Massey**（国别名单直接含 Canada/Australia，UBC+UniMelb 双双在名单内）；次之＝UC / Otago / Waikato / VUW（"substantially taught in English"/"recent degree taught in English" 即可，**均未要求 MOI 信**）；最麻烦＝**Auckland**（另有博士生专属 English Language Waiver Policy，须导师 support statement + Academic Head 背书，获批后还须做 DELNA）；**AUT 门槛最严**（写作单项要 6.5，且只认"近 3 年内"的英语授课研究生学习）。→ 结论：**不必考雅思，但 Auckland 与 AUT 建议各备一封英文授课证明，并把 IELTS 作为唯一稳妥对冲。**
- **⑦ GRE 全区不构成门槛**：7 校官方入学要求与材料清单均无 GRE；Auckland/UC/VUW/Waikato 可基本确认"不需要"，Otago/AUT/Massey 只能记 UNKNOWN（未提及）。**没有任何一所需要新考 GRE。**
- **⑧ 硕士未授予（2026 年末授予）不成问题，但只有 5 校有官方明文**：Auckland（未出终分可获 conditional offer，奖学金亦可 conditional）、Canterbury（"either completed or **currently in progress**"，GPA 5.5 线）、Otago（"conditional admission may be granted… full admission once completed satisfactorily"）、Massey（接受 **incomplete transcripts**，offer 可为 conditional）、VUW（offer 可 conditional，但"能否后补学位"未明文）；**AUT 是明确风险**——奖学金条例写 "Grades for the qualifying degree **must be available at the time of application**"；**Waikato 未明文**（UNKNOWN）。
- **⑨ 时间线（按紧迫度；今天 2026-10-31）**：**AUT 2026-11-01**（2027 年 2 月入学，只剩 1 天，跳过）→ **VUW 2026-11-01 轮**（官网原文 "November 2026 application round is now open"，**这是最近、最可行的一个真截止日**）→ Auckland 奖学金 2026-11-01 / 2027-02-01 / 05-01 / 08-01 → UC **2027-05-15**（10 月轮已于 2026-10-15 关闭，2027 下半年入学只剩这一轮）→ Otago 3/6/9/11 月季度轮 → Waikato 四轮但**日期未公布**→ **Massey 2027 入学轮已于 2026-10-01 截止**（下一轮 2027-08-01，等于放弃 2027 奖学金）。
- **⑩ 多 agent / 复合系统方向贴合度（按契合排）**：**Otago 最贴合**——School of Computing 官方写 "staff are active in several AI-based sub-disciplines, **including multi-agent systems**, where we create 'socially aware' software… social norms, trust and reputation"，几乎是其课题原话；**Auckland** 次之——School of Computer Science 的 **Civilised Agent Lab**（Jiamou Liu）做 debate-agent / multi-agent style-contract workflow，方向页列有 "Software Engineering / Systems Development and Evaluation"；**Canterbury** CSSE 有 "AI & Machine Learning" 组 + Software Engineering；**VUW ECS** 有 "AI for Service and Cloud Computing" 与 Software and Programming Group（分布式/云最接近）；**AUT SERG** 做过 "Architecting an **Agent-Based Fault Diagnosis Engine**"（软件+分布式+可靠性，与其 DS-Hns/有界验收叙事契合）；**Waikato 无多 agent 组**（只有 Formal Methods「可靠软件」与 WEKA ML）；**Massey 无多 agent 组**（Guesgen 环境智能、Ruili Wang NLP/会话问答）。→ **投递组合：主攻 Otago + Auckland（方向＋学费＋stipend 三重最优）；VUW 作为"不套磁也能投"的并行项；UC / Waikato 作为导师谈成后的补充；Massey（国别免英语最省事）与 AUT 作兜底。**
