## 10. 条件概率的算法（可复核、可改）

```
现状 p_now = v3 概率 + 材料 v1.3 加成（导师主导 +3 / 委员会 +1），上限 70
条件 p_cond = p_now
             + 18   若「导师接收 = 是/条件」且该行没有在途 warm lead
             + 12   若「可自费通道」（澳 / 新西兰 / 日本 / 澳门 / 资助确定性 = 低）
             上限 88
```

两个刻意的保守处理：
- **上限 70 / 88**：不声称「几乎确定」。全表没有一行的名额被学校书面确认，任何 ≥85% 的说法都是自欺。
- **warm lead 不重复加分**：澳门大学（已提交 + PI 回信）与 Concordia（已过初审）已经把「导师意愿」计进基线，再加 18 就是重复计算。
