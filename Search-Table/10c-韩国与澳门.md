## 三、分区结论

**「多 agent 复合系统」最贴合的组（按契合度）**

1. **KAIST SoC — Systems/Networks + Interactive Computing**：신인식（Insik Shin，移动/实时系统；其创业公司 Flooze 做 mobile AI agent）、Junehwa Song（mobile/ubiquitous 系统）、Ian Oakley（HCI/穿戴）。三人都在申请人 2026-10 的接触名单里；`cs.kaist.ac.kr` 的 Systems·Networks 与 Interactive Computing 两个方向直接对口「跨设备执行 + 有界验收」。
2. **POSTECH CSE — Large-Scale System Platform / Software Verification / Human-AI Interaction**（指南原文列出的研究领域）：对「编排 + 故障恢复 + 验收」是结构上最接近的落点；且 **Inseok Hwang** 已在申请人接触名单里。
3. **UM FISC（原 FST/CIS）— PhD in Computer Science**：官方按 Potential Supervisors 名单招生，申请人已提交申请且 PI 已回信，是唯一有**真实在途流程**的学校。
4. **MUST FIE — 智能科学与系统博士 / 人工智能博士**：名称层面直接命中「智能系统」，但课程细则与资助不透明。
5. GIST School of Computing（AI Graduate School，Media AI / Data AI / AI Theory）、UNIST CSE（系统与 AI）次之。

**保底项（录取概率高 + 资助覆盖得住）**

- **第一保底：UM（澳门）**。已提交 + PI 回信（warm lead 最强）；英语走 MOI 豁免；GRE 不需要；硕士在读可 conditional offer（2026 年末授予正好衔接）；资助两条腿 **MPDS MOP 20,000/月×48 月** 或 **TRA 起 MOP 12,500/月**，学费由补贴按月抵扣 → 只要拿到 offer，学费不是问题。硬约束：**同一学年只能投一次**，不能再补投 2nd Batch；**奖学金窗口 2027-01-08 关闭**。
- **第二保底：GIST**。**所有国际研究生自动获得**学费全免（3,607,000 KRW/学期）+ 月补贴 + RA（博士年均 13,740,000 KRW），不需单独申请、不需内诺、不需 GRE；2027 Fall 申请 2027-03-09 开放且日期已实锤。唯一风险：英语豁免需 GIST **事先批准**（发邮件即可解决）。
- **第三保底：UNIST**。官方明确 **不需要教授预先同意**、英语可用 MOI 证书豁免、学费全额 3,840,000 KRW/学期 + 政府奖学金博士最低 1,100,000 KRW/月，申请费仅 50,000 KRW。适合作为「不依赖导师先点头」的平行投递。
- **POSTECH 属「有 warm lead 的冲刺位」**，不是保底：资助最厚（2,200,000 KRW/月）但材料需邮寄+apostille，且事实上需实验室接收。

**韩国内诺制的具体时限（必须卡的时间点）**

- **KAIST（唯一「制度强制」内诺的学校）**：`cs.kaist.ac.kr` 明文规定博士申请者**必须在网申开始前**联系拟指导教师并取得许可，网申时要填 1 名导师 → 对 2027 Fall，**网申 2027-01-07 开放，内诺必须在 2026 年 12 月内完成**（留出改 SOP/材料的时间）。
- **其他学校**：POSTECH/UNIST/GIST/SNU/Yonsei/Korea 均**不要求**事先获得教授同意（UNIST FAQ 与 POSTECH 指南明示或未设此条）；但 POSTECH 的资助来自导师 RA、GIST 的英语豁免需事先批准、MUST/USJ 属小规模研究型 → 这三类仍需在 2027 年 1 月前把导师意向谈定。
- 时间轴建议：**2026-11~12 完成韩国 4 校（KAIST/POSTECH/GIST/UNIST）套磁** → **2027-01-07~02-05 KAIST 网申** → **2027-02~04 POSTECH 第 1 轮 + GIST（03-09~04-08）+ UNIST** → SNU 盯 2027-03 上旬的 3 天窗口。

**资助结构对比（一句话）**：GIST（自动、约 1.6M KRW/月）＞ POSTECH（2.2M KRW/月，需 lab）＞ UNIST（学费全免 + 1.1M 起）＞ KAIST（学费全免 + 院系 stipend + KPS 300k，靠 RA）＞ UM（MOP 20,000 或 12,500，含学费抵扣）＞ MUST/CityU（不透明）＞ Yonsei/Korea/SNU（无保证，可能自费）。
