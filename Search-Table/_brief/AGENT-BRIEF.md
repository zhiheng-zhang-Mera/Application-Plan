**关键推论（用于匹配判定）**：
1. 英语豁免 = 靠「英语授课学位」路径；加拿大/澳大利亚学位在美国、英国、香港、新加坡、加拿大绝大多数项目里属可豁免或可个案批准。**Bosworth 例外必须逐校核实**，凡官方写明"必须考试"的，直接记为不适用。
2. GRE = 硬门。凡官方要求必须提交且无 waiver 的项目，直接判 `排除(硬门槛)`，不进入匹配率讨论。
3. 学术门槛 = 风险点。本科含一次 F 的 attempt 均分 78.05%、硕士派生 67.5，对要求 First Class / 3.5+/85%+ 的项目是明显劣势；对"看后两年/看硕士/看研究潜力/导师主导"的项目影响小。
4. 无论文 = 对 committee 制美国 R1 是主要短板；对导师主导制（英/港/新/加/大陆）可用系统与证据链对冲。

## 2. 每所学校必须回答的 6 件事（用户指定）

1. **英语豁免政策**：是否可用「英语授课学位」豁免？对加拿大/澳洲学位是否明确适用？需要什么证明文件（如 medium-of-instruction 证明、院系函）？
2. **GRE 提交要求**：不需要 / 可选 / 建议 / 必须；有无 waiver 或 department code；对国际生是否不同。
3. **导师套磁与面试**：是否必须先联系导师？招生面试形式（委员会面 / PI 面 / 笔试 / 无面试）？
4. **录取是否必须导师接收**：是（必须先拿到导师同意/经费承诺）/ 否（委员会统一录取后再分配）/ 条件（部分 track 或部分导师）。
5. **奖学金制度**：全奖构成（学费减免 + 月度 stipend + 保险）、是否 guaranteed、金额与年限、是否有 TA/RA 义务、是否需单独申请、国际生限制。
6. **其它提交材料**：推荐信数量、SOP/PS/Research Proposal、Writing sample、成绩单与学位证明、申请费、语言成绩、其他特殊材料。

## 3. 输出表（强制格式，硬性要求）

写入文件 `D:\Random-Daily\Application-Plan\Search-Table\_raw\<slug>.md`，结构固定为：

```markdown
# <区域名> 2027 Fall CS PhD 检索原始表

> 检索代理：<slug>；核验日：YYYY-MM-DD；覆盖学校 N 所。
> 总体置信度：高/中/低 + 一句话理由。

## 一、明细表（每校一行）

| 州/省 | 学校 | 项目 | 2027F截止 | 英语豁免 | GRE | 套磁 | 面试 | 导师接收 | 资助 | 其他材料 | 学术门槛 | 匹配率 | 风险 | 来源 | 核验日 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| ... |

## 二、分区结论（≤10 条 bullet）

## 三、未能核实项（明确列出）
```

### 字段取值规范

- **英语豁免**：`适用` / `条件`（需补证明或个案审批）/ `不适用`（必须新考）/ `UNKNOWN`
  后接简短依据，例如 `适用（英语授课学位可免，需院系 MOI 证明）`。
- **GRE**：`不需要` / `可选` / `建议` / `必须` / `UNKNOWN`；必须项后接是否存在 waiver。
- **套磁**：`必须` / `建议` / `不必要` / `禁止` / `UNKNOWN`。
- **面试**：`有-委员会` / `有-PI` / `有-笔试+面试` / `可能` / `无` / `UNKNOWN`。
- **导师接收**：`是` / `否` / `条件` / `UNKNOWN`。
- **资助**：写清构成与是否 guaranteed，例 `全奖：学费全免+TA/RA，月 2,200 SGD，4 年，保证`；`无保证，仅可申请`；`需自费`。
- **学术门槛**：`达标` / `边缘` / `不达标` / `UNKNOWN`，依据须引官方表述（如"要求 First Class 或同等"）。
- **匹配率**：严格用下面 6 档之一（见 §4），必须带区间百分比。
- **风险**：≤40 字，指最致命的一个点（如"论文硬要求""必须导师先行""硕士未毕业""截止已过"）。
- **来源**：1–3 个**官方** URL（学校/院系/研究生院域名），用 `<br>` 分隔；禁止百科/中介/论坛。
- **核验日**：`YYYY-MM-DD`。

### 通用纪律（违反即整行作废）

- **不许编造**。查不到就写 `UNKNOWN`，并在第三节列出。宁可 30% 的格子是 UNKNOWN，也不要一个假的日期或金额。
- **只认官方页面**：`.edu` / `.edu.cn` / `.ac.uk` / `.edu.sg` / `.edu.hk` / `.ca` 学校域、研究生院、院系 admissions 页。中介博客、第三方排名站、留学论坛一律不作为依据。
- **区分学年**：若官网当前挂的是 2026/27 或 2026 Fall 页面，必须写 `沿用2026（官网未更新2027）`，不能伪装成 2027 实锤。
- **区分"页面上有"与"招生办确认"**：没写清楚的写 `UNKNOWN`，不要用"通常""一般来说"填充。
- 一行只写一所学校的一个主项目（一个学校多个 CS 相关 PhD track 时，选最贴合且最主流的那个，必要时加第二行）。

## 4. 匹配成功率评分口径（强制统一）

该列含义：**"若以当前材料在 2027 Fall 正式提交，收到录取的概率区间"**，是启发式估计，不是承诺，也不是录取保证。

| 档位 | 区间 | 典型特征 |
|---|---|---|
| 高 | 55–70% | 导师主导 + 已明确招人 + 免英语/GRE + 资助保证 + 学术门槛看硕士或研究潜力 + 有 warm lead |
| 中高 | 35–55% | 导师主导但无 warm lead，或委员会制但门槛宽松、规模大、国际生友好 |
| 中 | 20–35% | 委员会制中等竞争；或导师主导但资助需竞争 |
| 低 | 8–20% | 强 committee 制、排名高、论文期待高；或资金需全额竞争 |
| 极低 | <8% | 顶级项目 + 明确论文/成绩硬要求 + 无内部支持 |
| 排除 | — | 触发硬门槛：必须新考英语/GRE、必须已发表论文、必须已获硕士学位、截止已过且无下一轮 |

**加减分锚点（供推理，不必写进表）**：
- 加分：导师主导制、明确 2027 招人、英语豁免明确、GRE 不需要、资助保证、接受"硕士在读/未毕业"申请、接受 system/artifact 作为研究证据、有 warm contact。
- 减分：committee 统招且看重 publication、要求 First Class/Distinction 或 3.5+、要求已获硕士学位、要求 GRE、要求英语考试、只招有 funding 的自费、申请费高且无 fee waiver。
- 不要把"学校排名"当唯一变量；用户的核心约束是**免英语/GRE + 资助 + 导师接收可行性**。
