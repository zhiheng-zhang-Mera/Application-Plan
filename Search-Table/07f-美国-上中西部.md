## 二、分区结论（≤10 条 bullet）

- **英语豁免：** 该区 11 校中，Iowa（名单国家学位自动免）、Iowa State（英语为官方语言国家学位免）、Nebraska（英语为官方授课语言院校学位免）三家明确可凭 UBC/UniMelb 学位免考；K-State 名单含 Canada/Australia 但表述为「来自该国」，属条件；Kansas、Missouri S&T、WashU、Mizzou、SLU、Wichita 未取到明确条款；**U Minnesota 明确要求非英语母语者即使有英语授课学位也须提交 TOEFL/IELTS**（且是 TA 资格前置）。
- **GRE：** 不需要 = UMN（不接受）、Nebraska；可选 = Iowa、Iowa State、Kansas（强烈建议）、WashU；**必须 = Kansas State（非美学位，146V/151Q/3.0）与 Missouri S&T（V370/Q700/AW4.0）**，两校官网均未见 waiver 通道 → 按 BRIEF §4 判「排除」。
- **导师接收：** 真正把「先匹配导师」写进流程的是 Iowa State（major professor match 才发 offer）与 WashU（direct-admit 进实验室）；其余多为委员会统一录取，UMN/Kansas/Nebraska 均为入学后定导师。
- **资助确定性（国际生同等待遇）：** 保证型 = UMN（录取即保证）、WashU（系里兜底）、Iowa（手册承诺前 4 年）、Iowa State（前 2 年 TA 明文）；竞争型 = Nebraska、Kansas、MST、Wichita；未核实 = Mizzou、SLU。
- **最现实的三所（免 GRE + 免英语考试 + 有明确资助机制）：Nebraska、Iowa、Iowa State。** 三者都被官方要求/鼓励「先对导师方向」，用户应以「wearable/ubiquitous 长程 agent」对标 Nebraska 的 IoT/移动与系统组、Iowa State 的系统/软件组、Iowa 的系统/PL 组。
- **相对现实的低档可留作备选：** Missouri S&T 与 Wichita State 门槛低（系小人少），但 S&T 的 GRE 硬门槛、Wichita 的「无独立 CS PhD」使二者都需要额外确认才能进申请名单。
- **Kansas 与 U Minnesota 属「成绩先卡」：** KU 硬线 GPA ≥3.5（录取均值 3.6），UMN 明文要求「3.45 GPA 或以上」+ 研究潜力；以 78.05%（attempt 均分）与 67.5 派生 WAM 计，两校在纸面上都不达标。
- **WashU 是全表最不利的一所：** 强 committee、真正意义上的顶尖私校，且无论文；即使 GRE/英语都可豁免，录取概率仍只落在「低」档。
- **时间线：** 最早一批截止为 WashU/Nebraska（12/1）、UMN 12/15（奖学金轮）、Iowa State 12/15 提交（1/10 材料）、Kansas 12/15 优先；Iowa 1/1、K-State 1/8、UMN 1/5 为第二波；材料准备必须在 2026 年 11 月内完成。
