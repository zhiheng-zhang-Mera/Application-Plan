## 1. 百分比分档（替代原来的「高/中高/中/低/极低」）

## 2. 主线变更：为什么这次数字普遍上移 2 个百分点

主线由「Wearable 长程 agent」改为 **Reliable Multi-Agent Composite Systems（可靠的多智能体复合系统）**。这不是换个说法，而是把材料与方向对齐了：

| 新主线要素 | 对应的已有证据 |
|---|---|
| 多 agent 编排与仲裁 | **Codex Boss**（多 Agent 编排、证据接纳、完成判定） |
| 跨设备/跨进程复合执行 | **Utopia**（两个物理 Windows worker + Android/Web 控制、fault/replay）、**Digital-City PCF 700–728** |
| 长程任务的有界重规划与恢复 | **DS-Hns**（持久任务生命周期、重启恢复、终态证据） |
| 失败可解释与负结果保留 | **Quant-Ultra**（hash-chained 实验记录、HOLD/REJECT）、**Privacy Lens**（fail-closed、claim boundary） |
| 真实结果验收而非表面成功 | REX-890 独立复现与验收 |

模型上统一 **+2 个百分点**（`build_v3.py` 的 `MAINLINE_BONUS`）：新主线更主流、与项目组合一一对应，委员会与 PI 都更容易在 30 秒内定位你；但**不额外加码**，因为顶级校的瓶颈依然是成绩与论文质量。

另外：2 篇 arXiv 已确认「**只在 arXiv、未投期刊、均被收录**」——状态从此前的 `未核验` 变为 `已确认的 preprint`。它仍然是**未经同行评审**，因此在 committee 眼里约等于「有写作产出、无评审背书」，只能部分对冲「无论文」。

## 5. 双轴：录取概率 × 资助确定性

单看录取概率会误判，因为「能录但读不起」等于不能投。所以每行都标了**资助确定性**（从「资助」列官方原文判定）：

| 资助确定性 | 判定依据（原文关键词） | 含义 |
|---|---|---|
| **高** | guarantee / 保证 / 全奖 / 全额 / 自动考虑 / PGS / HKPFS / 覆盖学费 / graduate school 明确承诺 | 录取即有钱，或制度性覆盖 |
| **中** | 竞争性 TA/RA、需单独申请、usually / typically | 有钱但要看当年名额 |
| **低** | 无保证 / 不保证 / 非保证 / 自费 / 未公布 / limited | 只能自费或极不确定 |
| **未知** | 官方未写清 | 必须发信问 |

**保底 = 录取 ≥60% 且资助 ≠ 低**；**高成功率 = 录取 50–59% 且资助 = 高**。这两类合起来才是真正可以「保底」的选项。

## 11. 诚实边界

- 百分比是启发式点估计，**不是录取承诺**；扩区国家的很多政策「沿用上一年度」，已在各行标注。
- **资助确定性是关键词启发式判定**，会误判（尤其「未公布」与「竞争性」混杂的句子）；关键 3–5 所必须发信确认。
- **澳洲是「录取易、资助难」的典型**：RTP 国际生配额被联邦限制在 10%，录取概率是 stipend 概率的 2–4 倍（stipend 普遍 <10–15%）。所以澳洲不能用「录取概率高」来当保底，除非接受自费 AU$40–57k/年。
- 日本、欧洲大陆的岗位制博士**要求已获硕士学位**；申请人 2026 年末才授予，只能走「先联系 PI、以毕业为条件录取」的路径，实际时间线可能滑到 2028 春季。欧洲大陆（尤其德荷瑞）即使录了，博士是雇员岗位，**入学时间由岗位发布节奏决定**，不是你能排期的。
- **韩国 2027 年 3 月入学已全线截止**（国际轮在 2026-09～10 关闭），A 组实际目标是 2027 年 9 月；日本 2027 年 4 月窗口多数已关，主战场是 2027 年 10 月。
- 新西兰的低学费基石存在政策风险：RNZ 2026-08 报道国际博士生学费 "under review"，若变则「兜底防线」失效。
