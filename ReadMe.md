## 工作表维护规则

每次学校官网更新后，只改四类字段：

1. **Deadline**
2. **GRE / English / GPA hard requirement**
3. **Supervisor / recruitment status**
4. **Required documents**

不要因为某个 PI 一时不回复就马上删学校；先区分它是 **department-admission** 还是 **supervisor-match admission**。只有后者的“PI 不匹配”才会直接影响最终 offer。
