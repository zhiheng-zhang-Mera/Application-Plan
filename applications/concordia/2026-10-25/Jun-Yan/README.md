## 适配主题

**授权约束下的智能体恢复与结果证据**

将 Utopia 的执行记录、跨主机结果和恢复经验连接到 agentic/autonomous systems 与 resilient cyber-physical systems。

研究问题：在执行端失联时，以状态版本、后置条件与执行回执判断重试、等待、重新授权或停止，减少重复执行和假成功。

初始方法：从良性桌面任务与模拟 IoT 端点起步，注入断连、过期状态和摘要错误；比较固定重试与证据驱动恢复，记录重复效果、假成功率和恢复时延。
