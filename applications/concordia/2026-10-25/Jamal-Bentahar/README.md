## 适配主题

**多智能体信任、证据状态与恢复决策**

将项目中的可检查执行证据连接到 multi-agent trust、argumentation 与 formal verification。

研究问题：当多个组件报告过期或冲突的结果时，结合信任与任务状态能否改善恢复，同时避免错误隔离？

初始方法：建立有界任务模型，比较固定重试、仅信任评分与状态感知协调；评估可验证完成、不变量违反、误隔离和来源追踪。
