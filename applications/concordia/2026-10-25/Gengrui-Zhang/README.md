## 适配主题

**分布式智能体任务账本与选择性协调**

连接 DISCOS 的分布式系统、数据库、复制与 AI 基础设施，而非仅将项目描述为一般 LLM 应用。

研究问题：如何在分区、节点失效及重试条件下，让任务状态和副作用保持可解释的一致性，同时控制协调延迟？

初始方法：设计带版本与副作用标识的任务账本，对比中心化、最终一致和选择性协调；评估不变量违反、重复效果、完成率及恢复延迟。
