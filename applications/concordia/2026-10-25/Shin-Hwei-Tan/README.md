## 适配主题

**智能体工作流的独立测试判据与失败重放**

承接软件测试、程序修复与现代 agentic frameworks 缺陷研究，把已有项目轨迹变成可评估的测试方法。

研究问题：如何区分模型、框架与集成层故障，并用独立的状态判据识别表面成功但实际未完成的任务？

初始方法：把失败注入、状态观测与可复现重放组合起来，在多个框架中检验测试判据；评估错误检出率、误报、重现性及跨框架迁移。
