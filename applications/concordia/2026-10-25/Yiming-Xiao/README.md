## 适配主题

**VR/AR 辅助工作流中的状态新鲜度、确认与撤销**

连接 Health-X / SAMIRA 的人机交互、VR 辅助智能体与多组件工作流，并诚实区分 ESP32/手套探索、眼镜提案和已完成系统。

研究问题：将模型不确定性与应用状态新鲜度共同呈现，能否减少错误接受及恢复负担？

初始方法：从公开数据和非临床 VR 任务起步，比较固定确认、置信度提示和状态感知提示；注入延迟与乱序结果，评估任务错误、恢复代价和工作负荷。
