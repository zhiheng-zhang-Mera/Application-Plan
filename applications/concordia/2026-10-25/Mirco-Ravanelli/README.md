## 适配主题

**语音交互中的可靠性校准、澄清与保守执行**

把系统可靠性兴趣连接到 speech/conversational AI、鲁棒语音与 listenable explanations，不声称已有大型语音模型训练成果。

研究问题：在噪声、语音退化和任务风险变化时，如何决定执行、澄清或暂缓，并提供有用的可听解释？

初始方法：以 SpeechBrain 和公开音频数据开展受控退化实验，比较置信度阈值与校准策略，分析风险—覆盖率、延迟及解释可用性。
