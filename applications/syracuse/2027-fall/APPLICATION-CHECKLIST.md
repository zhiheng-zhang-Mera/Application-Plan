## 6. 收到 offer 后：独立核验资金和职责

- [ ] 录取信与 funding letter 是否同时到达；未有书面资助时标 FUNDING_UNCONFIRMED。
- [ ] 每学年究竟是 fellowship、RA、TA 还是混合；不同年份是否改变。
- [ ] 津贴的税前金额、发放月份、首次发薪时间及暑期支持。
- [ ] 学费减免覆盖学分、强制费用、医疗保险和个人自付项目。
- [ ] RA/TA 的具体工作、时间要求、续聘条件，以及研究与学位课题的关系。
- [ ] 保证年限、学业条件、导师/课题变化后资金是否可续。
- [ ] Fellowship 的无额外服务安排只适用于相应奖项期，不意味着以后不会改为 assistantship。
- [ ] 完整资金条件明确且可接受后，再作入学承诺。

不把此前现金流讨论里的情景数字当成已知 fellowship 金额或本人将获的资助底线。
