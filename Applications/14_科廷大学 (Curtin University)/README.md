## 学校特定检查

- [ ] 正式申请前先提交 Expression of Interest（EOI）。
- [ ] 研究计划正文控制在 2 页，参考文献放在单独附加页。
- [ ] 仅在 EOI 通过且导师明确支持后进入正式申请。
