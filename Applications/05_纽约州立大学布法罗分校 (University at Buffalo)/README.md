**计算机科学与工程博士申请不要求 GRE。** 全部学校的筛查记录见 [GRE_AUDIT.md](../GRE_AUDIT.md)。如果实时规则变为对当前申请背景强制要求 GRE，应暂停或删除该学校，不得绕过硬约束。

- [ ] 在线申请表及申请费，或获批的费用减免证明
- [ ] 学术简历和研究简历
- [ ] 简短个人陈述或目的陈述。
- [ ] 所有高等教育阶段的正式成绩单和最终学位证书
