## 0. 当前硬约束

- GRE mandatory 且无 waiver → reject；
- 必须新考 TOEFL/IELTS/DET 且英语授课学历无法 waiver → reject；
- 已确认 academic minimum 明显高于可比较成绩 → reject；
- 要求有实质 PhD funding / tuition coverage；
- pure-theory / proof-first / derivation-first → reject 或显著降权；
- 首次套磁前要求当前 supervisor capacity / recruitment signal；
- direct outreach 候选必须有公开可验证身份与联系方式；
- interview / QE / screening exam 属于摩擦，不必自动 reject，但同等条件下优先低摩擦。

## 1. 当前研究画像

默认主线已从单纯 AI4SE 扩展为：

**Utopia → personal compute fabric / ubiquitous agentic computing**

三个核心系统问题：

1. 跨异构设备的个人计算与 agent action substrate；
2. 长时 autonomous execution 的 persistence / recovery；
3. completion / decision 的 evidence / governance。
