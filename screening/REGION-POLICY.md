# 2027 PhD 地区筛选策略（2026-10-10 生效）

> **亚洲优先，美国、英国正式开放；加拿大原有效路线继续保留。** 这里只规定资源分配与优先级，所有硬性学术、英语、GRE、经费、考试与套磁协议门禁仍由 [SCREENING](../rules/SCREENING.md) 执行。

## 地区分层与执行秩序

| 层级 | 区域 | 原则 |
|---|---|---|
| 主池（Primary / 亚洲） | 香港、澳门、港校内地校区、新加坡；并可继续检索与规则相容的亚洲其他高校 | 主要投入：先处理暖线、面试、正式申请截止期，再挖掘同研究方向的新导师 |
| 扩展池（Secondary / US） | 美国博士项目（单列 NYU/上海等跨区域项目的实际就读地点） | 仅选教授近期招生、英语/GRE 门禁可过、有实质资助、研究方法非纯算法/芯片的方向；高竞争不自动淘汰 |
| 扩展池（Secondary / UK） | 英国导师制及大学奖学金 PhD | 优先明确国际生全额资助项目，必须检查 honours/first-class/distinction 等价、经费适用资格、导师接受新生及 funding 截止日期 |
| 保留池（Existing / Canada） | 已建立联系或有明确低摩擦路径的加拿大项目 | 保留 Concordia 的积极回复与其他有效历史；不为了开美国英国而删除 |

**重点是注意力分配而非人数配额。** 同样质量的候选优先推进亚洲；但美国/英国若确认全额资助、零新英语/GRE 考试、强导师匹配且材料投入合理，可升为当期 ACTIVE。

## 导师到正式发送的门禁

`DISCOVERED → RESEARCH_MATCHED → PROGRAM_GATE_CHECKED → RECRUITMENT_PROTOCOL_VERIFIED → PACKAGE_READY → OUTREACH_APPROVED → SENT → REPLIED / CLOSED`。

- 研究兴趣强不代表导师 2027 招生、学术成绩等价达标、拿到 funding 或获准发邮件。
- 必须保存 PI 官方主页、个人主页、lab、join/openings、官方项目页面、核验日与证据 URL。缺项标 UNKNOWN。
- 美国需逐项目确认 GRE optional/waiver、英语授课学位 waiver、资助 *覆盖国际学生*、实际 2027 deadline；不误用另一个学校/学院的 waiver。
- 英国逐项目检查 First Class/Distinction equivalency、国际生费差额、奖学金限额、RA/TA 或教学义务、申请与资助截止日期；不默认全奖，不建议自费作为主计划。
- 继续允许有准备窗口且负担合理的专业考试，不把综合考试存在本身当 REJECT。
- 当前向同校/同系导师发新 cold email 前先对账已有 WAITING、INTERVIEW、warm 线程，默认一个学校一位当前 cold PI；已有积极互动时先完成其沟通。
- 不强迫导师承接 Celestial 原架构；对外使用实际已完成/冻结的 DS-Hns、Codex Boss、Utopia 及有界 PCF/REX 证据。无论文发表不伪称有 publication。
- 此筛选策略、`POOL` / `WATCH` 不是发送授权；Gmail/正式 portal 任何提交均须单独核验并获用户明确指示。
